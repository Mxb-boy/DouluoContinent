# 接口使用说明

## 属性接口

脚本位置：

```lua
Script/property/property.lua
```

使用前先引用：

```lua
local Property = UGCGameSystem.UGCRequire("Script.property.property")
```

一般传入当前玩家角色：

```lua
local PlayerPawn = UGCGameSystem.GetLocalPlayerPawn()
```

### 获取基础属性

```lua
local hp = Property.GetCurrentHP(PlayerPawn)
local maxHp = Property.GetMaxHP(PlayerPawn)
local attack = Property.GetAttack(PlayerPawn)
local zhanli = Property.GetCombatPower(PlayerPawn, PlayerPawn)
```

说明：

- `GetCurrentHP`：当前血量，读取属性 `Health`
- `GetMaxHP`：最大血量，读取属性 `HealthMax`
- `GetAttack`：最终攻击力，读取属性 `AttackPower` 后叠加固定和百分比加成
- `GetCombatPower`：战斗力，公式为 `攻击力 + 最大血量 * 12345`

### 攻击力加成

固定攻击力：

```lua
Property.AddAttackFlat(PlayerPawn, "Weapon_001", 50)
```

表示来源 `Weapon_001` 给角色增加 `50` 点攻击力。

百分比攻击力：

```lua
Property.AddAttackPercent(PlayerPawn, "Weapon_001", 100)
```

表示来源 `Weapon_001` 给角色增加 `100%` 攻击力。

获取当前所有攻击百分比总值：

```lua
local percent = Property.GetAttackPercentTotalValue(PlayerPawn)
```

返回值是百分数，例如 `150` 表示总共增加 `150%` 攻击力。

### 血量加成

固定血量：

```lua
Property.AddHPFlat(PlayerPawn, "Weapon_001", 500)
```

表示来源 `Weapon_001` 给角色增加 `500` 最大血量。

百分比血量：

```lua
Property.AddHPPercent(PlayerPawn, "Weapon_001", 100)
```

表示来源 `Weapon_001` 给角色增加 `100%` 最大血量。

获取当前所有血量百分比总值：

```lua
local percent = Property.GetHPPercentTotalValue(PlayerPawn)
```

返回值是百分数，例如 `100` 表示总共增加 `100%` 最大血量。

### 移除加成

移除某个来源的攻击力加成：

```lua
Property.RemoveAttackBonus(PlayerPawn, "Weapon_001")
```

移除某个来源的血量加成：

```lua
Property.RemoveHPBonus(PlayerPawn, "Weapon_001")
```

同时移除某个来源的攻击力和血量加成：

```lua
Property.RemoveBonus(PlayerPawn, "Weapon_001")
```

### 刷新 UI

```lua
Property.RefreshUI(UIInstance, PlayerPawn)
```

当前绑定的 UI 控件：

- `ProgressBar_122`：血量进度条
- `hp`：血量文本，显示 `当前血量/最大血量`
- `gjl`：攻击力文本
- `TextBlock_303`：战斗力文本

`UI02.lua` 已经每 `0.2` 秒自动刷新一次。

## 飞行按钮

脚本位置：

```lua
Script/Blueprint/UI/Fei.lua
```

按钮：

```lua
Button_84
```

按住按钮：

- 开始飞行
- 隐藏其他蓝图 UI
- 隐藏攻击、跳跃、蹲伏、趴下、换弹、背包等原生按钮
- 播放飞行动画
- 生成飞行粒子

松开按钮：

- 停止飞行
- 恢复 UI
- 恢复原生按钮
- 恢复人物动画蓝图
- 销毁飞行粒子

## 玩家属性来源

项目使用属性系统里的这些字段：

```text
Health      当前血量
HealthMax   最大血量
AttackPower 攻击力
```

其中 `AttackPower` 是自定义属性，默认值为 `40`。

## 示例：武器同时加攻击和血量

```lua
local Property = UGCGameSystem.UGCRequire("Script.property.property")
local PlayerPawn = UGCGameSystem.GetLocalPlayerPawn()

Property.AddAttackFlat(PlayerPawn, "Sword_001", 50)
Property.AddAttackPercent(PlayerPawn, "Sword_001", 100)
Property.AddHPFlat(PlayerPawn, "Sword_001", 500)
Property.AddHPPercent(PlayerPawn, "Sword_001", 50)
```

效果：

- 固定攻击力 +50
- 攻击力 +100%
- 最大血量 +500
- 最大血量 +50%

卸下武器时：

```lua
Property.RemoveBonus(PlayerPawn, "Sword_001")
```

## 按钮点击态

按钮点击态工具脚本：

```lua
Script/Common/UIEffectUtil.lua
```

使用前先引用：

```lua
local UIEffectUtil = UGCGameSystem.UGCRequire("Script.Common.UIEffectUtil")
```

### 单个按钮添加点击态

```lua
UIEffectUtil.SetButtonStateBrushSameAsNormal(self.Button_126)
UIEffectUtil.BindPressScale(self, self.Button_126, self.Button_126, 1.06, 1.0)
```

说明：

- `SetButtonStateBrushSameAsNormal`：让按钮按下/悬停状态使用普通状态图片，避免切图不一致
- `BindPressScale`：按下时放大，松开时恢复
- `1.06`：按下时缩放比例
- `1.0`：松开后恢复比例


### 推荐封装写法

在 UI 脚本里先写一个方法：

```lua
function UI02:ApplyButtonEffect(Button)
    UIEffectUtil.SetButtonStateBrushSameAsNormal(Button)
    UIEffectUtil.BindPressScale(self, Button, Button, 1.06, 1.0)
end
```

然后给按钮调用：

```lua
self:ApplyButtonEffect(self.Button_126)
self:ApplyButtonEffect(self.Button_84)
```

这样以后新增按钮，只需要加一行：

```lua
self:ApplyButtonEffect(self.按钮名)
```
